Ciclo KM

Flujo de gestión del conocimiento

  1. Identificar: seleccionar documentos, guías, protocolos, FAQ y experiencias clave.
  2. Capturar: registrar título, fuente, categoría, etiquetas y contenido verificable.
  3. Indexar: fragmentar el conocimiento para búsqueda documental/semántica.
  4. Aplicar: usar el tutor IA y medir trazabilidad por historial y auditoría.
Calidad

Criterios antes de cargar

  • Contenido claro, actualizado y relacionado con el proyecto.
  • Fuente identificable para trazabilidad académica o institucional.
  • Etiquetas coherentes para recuperación rápida.
  • Categoría correcta: académico, institucional, técnico o FAQ.
